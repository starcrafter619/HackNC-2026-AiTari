# AiTari
By: Ananya Bandaru, Sreeja Marupalli, Anahitha Raffe Sofia, Karissah Yap

# What is our project?
Our project is a study tool that combines the commonly used pomodoro timers and an AI chatbot that can help "tutor" the user. The user will be able to input their own notes, which will then be read by the chatbot, powered by Gemini API, to respond to questions by the user. The chatbot runs like any other chatbot, but mostly using your own notes to help you study. The chatbot can create quizzes and summarized study guides to help you study as well. # Inspiration
As the theme is Frutiger Aero, we thought about some classic icons of the early 2000s. One of them being retro gaming consoles like GameCube or Nintendo Entertainment Systems. We ended up choosing Wii, which is a console where you insert a game card to play on a television, and we based the interface based on that. For our name we also used the classic game Atari as our inspiration and named our group and program name to "AiTari" combining Atari and AI. 

# Main tools used
1. Penpot - Tool used to create the UI for the program. We used its features to turn it into code and then implemented the API into that code and updated the visual components as necessary.
2. Gemini API, gemini-3.8-flash - API and version used to create the AI tool in the program. 
3. JavaScript, Node.js, HTML, CSS - Main coding languages for the program. 
4. Render - tool used to deploy the website and make it public.

# AI usage
We primarily used Gemini Pro and Claude to work on this project. Initially we used Claude to understand and develop starter code for making the API work for our context. But then we realized it would be better to use Gemini since the API is literally Gemini API and the LLM would probably know better about the API than Claude. Which then helped us finally make the API work. We also used it to identify and easily deploy the program into a publicly visible website.
